# Chill Movie Web
 
Project Based Bootcamp Harisenin — landing page aplikasi streaming film bergaya Netflix, dibangun menggunakan HTML dan Tailwind CSS.
 
## 🛠️ Tech Stack
 
- **HTML5** — struktur halaman
- **Tailwind CSS** — styling (via CDN)
## 📁 Struktur Folder
 
```
chill-movie-web/
├── assets/
│   ├── movie/
│   │   ├── portrait/      # poster film (rasio potret)
│   │   └── landscape/     # thumbnail film (rasio landscape)
│   ├── logo/               # logo aplikasi
│   ├── avatar/             # avatar pengguna
│   └── icons/               # icon-icon UI
├── index.html
└── README.md
```
